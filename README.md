# cosmogram-front

**Українська** · [English](README.en.md)

Фронтенд Cosmogram — вебзастосунку, який за датою, місцем і (за бажанням) часом народження будує натальну карту, Матрицю Долі та Квадрат Піфагора з тлумаченнями простими словами.

**Демо:** [cosmogram-front.vercel.app](https://cosmogram-front.vercel.app)

Розрахунки виконує окремий бекенд (Express + MongoDB, репозиторій `cosmogram-back`). Цей репозиторій — інтерфейс: форма, візуалізації, кабінет і шеринг.

## Можливості

- **Без реєстрації.** Гість одразу бачить результат; акаунт потрібен лише, щоб зберегти карту. Якщо гість реєструється після розрахунку, карта зберігається автоматично.
- **Натальна карта.** Колесо з планетами, домами й аспектами, список позицій і баланс стихій. Час народження необов'язковий: без нього карта рахується на полудень, а доми й асцендент не показуються — і інтерфейс прямо про це каже.
- **Матриця Долі.** Октаграма в класичному розташуванні з підписаними позиціями A–H, лінія призначення, родові програми, канали грошей і стосунків.
- **Квадрат Піфагора.** Класична сітка (верхній рядок 1-4-7) з робочими числами і вісім ліній.
- **Тлумачення всього.** Будь-яку планету, аспект, аркан, клітинку чи лінію можна натиснути й прочитати, що вона означає саме в цій позиції. Над результатом — короткий підсумок: Сонце, Місяць, Асцендент, провідна стихія й центр матриці.
- **Кабінет.** Збережені карти, редагування даних (бекенд перераховує карту), видалення.
- **Шеринг.** Публічне посилання на карту, яке можна вимкнути; персональне OG-прев'ю з ім'ям, знаком Сонця й центром матриці.
- **Три мови:** українська, англійська, польська.
- **Доступність:** skip-link, керування з клавіатури, `aria`-атрибути, повага до `prefers-reduced-motion`.

## Стек

- [Next.js 14](https://nextjs.org/) (App Router) + TypeScript (`strict`)
- CSS Modules з дизайн-токенами в `globals.css`
- [zustand](https://github.com/pmndrs/zustand) — авторизація, профілі, гостьовий розрахунок
- [react-hook-form](https://react-hook-form.com/) + [zod](https://zod.dev/) — форми й валідація
- [axios](https://axios-http.com/) — запити до API з оновленням токенів
- `next/og` — генерація OG-зображень
- Власна легка i18n без сторонніх бібліотек

## Запуск локально

Потрібні Node.js 18+ і запущений бекенд `cosmogram-back`.

```bash
npm install
cp .env.local.example .env.local   # і вкажіть свої значення
npm run dev
```

Якщо бекенд і фронт локально претендують на той самий порт, запустіть фронт на іншому: `npm run dev -- -p 3001`.

### Змінні середовища

| Змінна | Призначення |
|---|---|
| `NEXT_PUBLIC_API_URL` | Базовий URL бекенду разом із префіксом `/api` |
| `NEXT_PUBLIC_SITE_URL` | Адреса самого фронту. З неї Next будує абсолютні URL для OG-тегів і canonical — без неї прев'ю посилань у соцмережах не збираються |

Обидві змінні публічні (`NEXT_PUBLIC_` потрапляє в браузер), тож секретів у них бути не повинно.

### Скрипти

## Структура

```
src/
  app/          — роути App Router: головна, login/register, profile, preview, share,
                  а також error/loading/not-found і opengraph-image
  components/   — компоненти за розділами (birth-form, cosmogram, dashboard, layout, ui…);
                  кожен у власній папці: Component.tsx, Component.module.css, index.ts
  hooks/        — перевикористовувані хуки
  i18n/         — словник інтерфейсу (dictionaries.ts) і предметні тексти:
                  тлумачення планет, знаків, арканів, стихій, квадрата
  mocks/        — приклад результату для головної
  services/     — клієнти API
  store/        — zustand-сховища
  types/        — спільні типи
  utils/        — утиліти
```

## Про методи розрахунку

Розрахунки робить бекенд; фронтенд лише показує результат і пояснює його.

- **Натальна карта** — положення планет за ефемеридами, доми й аспекти.
- **Матриця Долі** — метод Наталії Ладіні: A — день, B — місяць, C — сума цифр року, D — їхня сума, центр — сума всіх чотирьох; числа понад 22 згортаються додаванням цифр.
- **Квадрат Піфагора** — класичний метод з чотирма робочими числами.

Тлумачення написані описово, без передбачень. Матриця Долі й Квадрат Піфагора — інструменти самопізнання, а не наукові методи, і застосунок про це прямо пише.

## Деплой

Фронтенд розгорнуто на Vercel. Для продакшну задайте `NEXT_PUBLIC_API_URL` (адреса задеплоєного бекенду) і `NEXT_PUBLIC_SITE_URL` (домен фронту), а на бекенді додайте домен фронту в `CORS_ORIGINS`.

OG-зображення працюють на edge-runtime: у Next 14 node-версія `next/og` ламає збірку на Windows через спосіб, яким будує шлях до вбудованого шрифту.
